# UC ARC9 Port

A port of the ArcCW Urban Coalition addons (Urban Decay, Urban Renewal, the HK USP, and UC Commons) to the ARC9 weapon base. It includes all 17 weapons and their attachments.

## Install

Requires the [ARC9 Weapon Base](https://steamcommunity.com/sharedfiles/filedetails/?id=2910505837).

Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3812993432), or clone this repository into `garrysmod/addons/`.
